# AI Nexus – Faculty Development Programme on AI Tools

## Project Overview
AI Nexus is a multi-page website developed for the Faculty Development Programme on AI Tools. It provides information about programme objectives, sessions, resource persons, registration, and contact details.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## Project Folder Structure
- `index.html` – Home page
- `about.html` – Programme details
- `sessions.html` – Sessions and resource persons
- `register.html` – Registration form
- `contact.html` – Contact information
- `evidence.html` – Testing and evidence
- `report.html` – Project report
- `style.css` – Website styling

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the website using the menu.

## Features
- Multi-page website
- Programme information
- Sessions and resource persons table
- Registration form
- Consistent CSS styling
- Navigation between pages
